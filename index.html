¿Cómo se envía el correo?

Esta versión está preparada para funcionar como sitio 100% estático en GitHub Pages. Genera el Excel y PDF directamente en el navegador y abre un borrador de Gmail con el asunto y resumen ya preparados.

Importante: un HTML alojado en GitHub Pages no puede usar directamente una contraseña de aplicación de Gmail para conectarse al servidor SMTP de Google. La contraseña tampoco debe guardarse, aunque esté codificada en Base64/JSON, porque cualquier visitante podría recuperarla.

Después de abrir Gmail, adjunta los archivos Excel y PDF que la aplicación descargó. En teléfonos compatibles, también puedes usar la opción de compartir archivos generados.

¿De dónde salen los productos y códigos?

No existe una lista pública oficial con "todos los códigos QR/barras" de Tottus, Metro o Wong, así que no se puede inventar una sin que tenga errores. Esta app funciona con códigos reales: escaneas con la cámara el código de barras o QR que trae el producto, y la primera vez que aparece un código nuevo, te pide el nombre del producto y lo recuerda para la próxima vez (se guarda en este navegador). También puedes importar tu propio catálogo desde un Excel/CSV con columnas codigo, nombre en ⚙️ Configuración.
